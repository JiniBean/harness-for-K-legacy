# transcript-grep

Cursor·Claude Code 대화 기록(jsonl)을 정규식으로 검색하는 도구. 지난 대화의 교정·결정·명령을 다시 찾을 때 쓴다.

## 사용자 안내

설명: 예전에 에이전트와 나눈 대화에서 특정 말이나 결정을 찾아야 할 때 에이전트가 이 도구로 대화 기록을 검색합니다.

물어볼 것: 없음(`[묻지 않음]`).

## 포함 파일과 설치 위치

- `scripts/transcript_grep.py` → `<.agents>/scripts/transcript_grep.py`. `<.agents>`는 전역 설치면 `~/.agents`, 프로젝트 설치면 `<프로젝트>/.agents`
- 사용법은 스크립트 docstring(인자 없이 실행하면 usage)
