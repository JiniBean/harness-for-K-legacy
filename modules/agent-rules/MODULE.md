# agent-rules

에이전트의 응답·작업 태도 공통 규칙(언어, 확인 방식, 추측 반복 금지, 에이전트 간 호출, 파일 생성 위치, 도구 우선순위, 응답 프로토콜, 서식, 코딩 기본값 YAGNI). 프로젝트 내용은 넣지 않는다.

## 사용자 안내

설명: 어떤 프로젝트에서든 에이전트가 같은 말투·확인 방식·작업 습관을 따르게 하는 공통 규칙입니다. 전역으로 깔면 모든 프로젝트에 한 번에 적용됩니다.

물어볼 것: 없음(`[묻지 않음]`). set-up-harness 3단계 표에서 기본으로 켜 두고, 끄거나 위치를 바꾸는 것은 번호로만 받는다.

## 포함 파일과 설치 위치

- `AGENTS.md`
  - 전역: `~/.agents/AGENTS.md`로 링크. 도구 연결은 `install.py global --tools ...`를 다시 실행하면 만든다(Claude `~/.claude/CLAUDE.md` import 줄, Codex `~/.codex/AGENTS.md` 링크, Cursor는 User Rules에 붙여 넣기 안내)
  - 프로젝트: 내용을 프로젝트 루트 `AGENTS.md` 앞부분의 공통 규칙 절로 옮긴다. 이미 같은 규칙이 있으면 겹치는 문장은 넣지 않는다
- 이 파일의 「코딩 기본값 (YAGNI)」 절은 여기 그대로 둔다(ponytail 스킬로 옮기지 않음)
- 응답 지적 처리(response), 코드 최소화(ponytail), 교정 정리(memory-tidy)를 가리키는 줄은 그 기능을 켜지 않았어도 남겨 둔다. 스킬이 없으면 규칙 문장만 적용된다
