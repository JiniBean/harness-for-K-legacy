## 첨부 — 토큰은 파일만 (Jira)

채팅에 토큰을 붙여넣는 방법은 없다. `{paths.jira_token_file}`에 2행(이메일, 토큰).

`download_attachments.py <KEY>-7217` → `.agents/tmp/<KEY>-7217_{원본파일명}`. 토큰 파일이 없으면 전환은 하고 첨부는 보류.

## 집계 호출 (Jira)

MCP 검색 결과가 파일로 저장되면:

```text
python .agents/skills/issue-flow/scripts/aggregate_assigned.py <저장된 파일> --start-status "<착수 상태>" --status-order "<상태1>,<상태2>" --sort-field <필드 이름>
```

stdout의 `---STATUS---` / `---REVIEW---`로 §1·§2를 채운다. 셸 `python -c`로 집계하지 않는다.

## 요청 붙여넣기 (도구 없음)
