# oz

OZ Report(.ozr/.odi)를 쓰는 프로젝트의 기능. 바이너리 안전 편집, 정적 검사, 셸 텍스트 쓰기 차단을 만든다.

## 사용자 안내

설명: OZ 리포트 파일(.ozr/.odi)은 텍스트로 저장하면 OZ Designer가 열지 못하게 깨지는 파일이라, 에이전트가 전용 도구(`oz_tool.py`)로 바뀌는 바이트만 고치게 하고 일반 편집·셸 쓰기는 훅이 막습니다. 고친 뒤에는 Designer가 열 수 있는 상태인지 도구로 점검합니다.

물어볼 것

1. `[못 찾을 때]` (프로젝트에서 `.ozr`·`.odi`를 찾지 못했을 때만) 이 프로젝트에서 OZ 리포트를 고치나요?
   - 정하는 것: 이 기능 설치 여부. 프로젝트에 `.ozr`가 있으면 묻지 않고 설치한다
   - 선택지: 예(리포트 원본이 프로젝트 밖에 있음) / 아니오
   - 추천: 아니오
   - 모름/나중에: 아니오(설치하지 않음). 나중에 다시 설치할 수 있다
2. `[처음 쓸 때]` (1에서 예일 때) 프로젝트 밖 리포트 원본 폴더(`[paths] oz_src`)
   - 설치 때: 묻지 않고 비워 둔다. 처음 리포트 작업을 할 때 에이전트가 묻고 적는다(`agents/ozbot.md` 「처음 쓸 때 확인」)

묻지 않고 정하는 것

- OZ 버전·뷰어 경로·리포트 폴더 구조·폰트 지정 방식: 코드에서 찾은 내용 그대로 리포트 폴더 `AGENTS.md`에 적는다
- 새 리포트 작업 때 본보기 리포트: 정하지 않는다. 작업 때 같은 모듈의 리포트에서 찾는다

## 감지 신호

- `*.ozr`, `*.odi`
- OZ 서버·뷰어 경로(`ozServlet` 등 웹 설정), 화면에서 리포트를 부르는 코드

## 원칙

- 기술 규칙은 `rules.md`
- `.ozr`는 바이너리 헤더(24바이트) 뒤에 XML이 오는 파일이다. 텍스트 편집 도구나 XML 재직렬화로 고치지 않고 `oz_tool.py`로 바이트 단위로 바꾼다
- 줄바꿈·BOM·인코딩을 바꾸지 않는다. `.odi`는 CRLF를 유지한다
- 고친 뒤에는 `oz_tool.py check`로 점검하고 크기 변화를 확인한다
- 셸로 `.ozr`/`.odi`에 텍스트를 쓰는 명령은 훅이 막는다

## 규칙 작성 항목 (set-up-harness가 채움)

| 항목 | 읽을 곳 |
|---|---|
| OZ 버전·뷰어 경로 | 웹 설정, 뷰어 폴더 |
| 리포트 폴더 구조 | 리포트 원본 폴더 |
| 폰트 동적 적용 방식(파라미터 이름, 폰트 표) (「폰트 동적 적용」 절. verify C_OZ가 이 절 이름으로 찾음) | 기존 리포트의 `OZPARAMS`, DB 설정 |
| 리포트 호출 방식 | 화면 코드 |
| `oz_tool.py` 사용 지시 (패치 스크립트에서 import, `dump`로 조사, 패치 후 `check`) | `rules.md` §3을 리포트 폴더 `AGENTS.md`에 그대로 두고, 경로를 설치 위치 `.agents/scripts/oz_tool.py`로 맞춘다. 함수·인자 설명은 `oz_tool.py` docstring에만 둔다 |
| `check` 점검 항목 설명 (헤더, 중복 CR, `.odi` CRLF, 동일 컴포넌트 사본, 고아 테이블 라벨, XML 적격성) | `rules.md` §5. 항목은 `oz_tool.py`의 `check()`와 같아야 한다. 기존 리포트 일부는 원래 FAIL이므로 패치 전 기준 결과를 남기는 절차를 함께 둔다 |
| 변경 되돌리기 명령 | 형상관리 도구 |
| 참고 선례 리포트 | 정하지 않음 (사용자 안내 「묻지 않고 정하는 것」). 작업 때 같은 모듈에서 찾는다 |
| 리포트 원본 폴더가 프로젝트 밖일 때 | 설치 때 비워 둠. 처음 리포트 작업 때 → `[paths] oz_src` |

결과 → 리포트 폴더의 `AGENTS.md`

## 포함 파일

- 규칙 `rules.md` → 리포트 폴더 `AGENTS.md`의 바탕
- 도구 `scripts/oz_tool.py` → `.agents/scripts/oz_tool.py` (패치 라이브러리, `check`, `dump`, `selftest`)
- `verify.md` → `.agents/skills/verify/checks/oz.md` (C_OZ)
- 훅 `hooks/oz_file_guard.py`, 설정 조각 `harness.fragment.toml` (셸 텍스트 쓰기 차단 패턴. 패턴마다 `# sample:` 주석으로 막아야 할 명령 예를 붙인다. 패턴을 고치면 하네스 저장소에서 `hooks/tests/test_oz_fragment_patterns.py`로 확인. 이 테스트는 설치하지 않는다)
- 서브에이전트 `agents/ozbot.md` → `.agents/agents/ozbot.md` (C_OZ 정적 검사, mode=plan 계획용 분석)
