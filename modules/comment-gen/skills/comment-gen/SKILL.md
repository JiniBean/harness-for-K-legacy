# comment-gen

값 표기 `{…}`는 `.agents/harness.toml`의 같은 키를 Read해서 쓴다. 주석 형식·대상 파일·금지 구간은 `[comment-gen]`, 작성자는 `[person] author`.

수정·추가된 코드에 변경 이력 주석을 반영한다.

## 처음 쓸 때 확인

시작할 때 `[person] author`가 비어 있으면 작성자를 지어내지 않고 먼저 묻는다.

1. 한 문장으로 설명한다: "변경 이력 주석에 넣을 작성자 이름이 아직 정해지지 않아, 주석에 적을 이름을 알려 주셔야 합니다"
2. 받은 이름을 `.agents/harness.toml` `[person] author`에 편집 도구로 적는다(UTF-8, BOM 없음). 다른 키·절은 건드리지 않는다
3. 이어서 아래 절차를 진행한다

## 입력

- 설명 문구: 있으면 그대로. 없으면 현재 작업 기준으로 제안
- 날짜 힌트: 있으면 아래 파싱 규칙. 없으면 오늘
- 티켓: 아래 조회 순서. 임의 생성 금지

## 티켓 조회

먼저 잡히면 멈춘다. 키 형식은 issue-flow 기능 규칙(켜지 않았으면 사용자 입력만).

1. 이번 메시지에 있는 티켓 키
2. 이번 대화의 티켓 키
3. 이슈 관리 도구 MCP 조회(issue-flow 기능을 켰을 때): 내 담당·진행 중 상태. summary가 현재 작업과 맞으면 1건만 사용, 2건 이상이면 키만 나열
4. 못 찾으면 티켓 부분을 넣지 않고, 배치안에 조회 경로를 한 줄로 적는다

## 주석 형식

`[comment-gen] format`(예: `YYYY.MM.DD {author}: {접두} {작업내용}({티켓})`). 화면과 리포트를 나누는 프로젝트는 `[comment-gen] report_format`도 쓴다.

- 접두(메뉴명·리포트명 등)의 출처: 이번 메시지·대화·계획 → 이슈 필드(`[tracker.fields]`) → 프로젝트 메뉴 문서. 임의 창작 금지
- 접두를 못 찾으면 접두 없이 작업내용만 쓰고, 배치안에 `접두 미확정` 한 줄

## 날짜 파싱

기준일은 오늘. 출력은 `YYYY.MM.DD`.

| 표현 | 규칙 |
|---|---|
| (없음) | 오늘 |
| `27일` | 이번 달 27일 |
| `9월1일` / `9월 1일` | 올해 9월 1일 |
| `9월` | 올해 9월 + 오늘 일 |

## 모드

### Plan 모드

1. 티켓 조회
2. 대상 코드를 분석하고 접두를 확정
3. 계획에 "주석 추가" 단계·문구·위치 후보를 넣는다
4. 소스 파일은 고치지 않는다

### Agent 모드

1. 티켓 조회, 대상 분석
2. 배치안 제시: 파일 경로, 위/옆, 대상 요약, 최종 주석 문자열, 스킵 사유, 티켓 출처
3. 사용자가 `진행`이라고 하기 전에는 파일을 고치지 않는다
4. `진행`이면 주석만 추가한다. 로직·포맷·리팩터 금지

## 대상 코드

1. 이번 대화에서 추가·수정한 코드
2. git working tree 변경분
3. 사용자가 `@`로 지정한 파일·구간

수정·추가된 위치마다 주석을 단다. 관련 없는 기존 코드에는 넣지 않는다.

## 파일 종류·문법

`[comment-gen] file_types`(확장자 → 주석 문법)와 `[comment-gen] exclude`를 따른다. 목록에 없는 파일은 제안만 하고 사용자 확인을 받는다.

- `exclude`의 각 항목은 `"<파일 glob>: <금지 구간>"`이다. glob에 맞는 파일에서는 적힌 구간에 주석을 넣지 않는다. 구간이 「밖 전체」로 적혀 있으면 그 구간 안에만 넣는다
- 금지 구간 안의 변경은 배치안에 스킵 사유(`금지 구간`)로 적는다

## 위치

- 여러 줄·기능 단위 변경 → 변경 블록 바로 위(구조상 추가가 시작되는 줄 위)
- 한 줄 변경 → 같은 줄 끝
- 주변 기존 이력 주석의 위치·구두점·들여쓰기·빈 줄·세로 정렬을 그대로 따른다
- 새 주석만 튀는 공백·빈 줄 추가 금지

## 금지

- 작성자·티켓·접두 임의 창작
- 금지 구간에 주석
- `진행` 없이 Agent 모드에서 파일 수정, Plan 모드에서 파일 수정
- 주석과 무관한 코드 변경
